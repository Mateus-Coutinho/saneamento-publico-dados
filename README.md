\# Análise de gastos com saneamento



Projeto de análise de dados públicos sobre gastos com saneamento.



\## Fonte dos dados



Base \*\*RIPSA — Recursos, Dimensão 5: Recursos Financeiros — Gasto com Saneamento\*\*, disponível no \[Portal Brasileiro de Dados Abertos](https://dados.gov.br/dados/conjuntos-dados/ripsa-recursos-dimensao-5-recursos-financeiros-gasto-com-saneamento).



\## Objetivo



Demonstrar habilidades de análise de dados com Python, explorando e visualizando os dados com as bibliotecas Pandas e Matplotlib.



\## Ferramentas



\- Python

\- Pandas

\- Matplotlib

\- Jupyter Notebook



\## Como visualizar



Abra o notebook `notebooks/gastos\_publico.ipynb` para acompanhar a análise.
